## 1. Project Overview

Customer Feedback Sentiment Analysis is a data analytics project developed using Python. The project focuses on analyzing customer reviews to understand their opinions and satisfaction levels.

A synthetic dataset containing 1,000 customer reviews was generated for this project. Each review includes a product category, rating, written feedback, review date, and sentiment label. The project analyzes positive, negative, and neutral feedback to identify customer satisfaction patterns.

## 2. Project Scope

The scope of this project includes:

- Generating a dataset containing 1,000 customer reviews.
- Loading and inspecting the dataset using Pandas.
- Analyzing customer ratings and sentiment categories.
- Counting positive, negative, and neutral reviews.
- Calculating average ratings for different product categories.
- Comparing sentiment distributions across products.
- Creating visualizations using Matplotlib.
- Exporting sentiment summaries, product-wise analysis, charts, and a final report.

## 3. Project Objectives

- Understand customer feedback and satisfaction patterns.
- Identify the distribution of positive, negative, and neutral reviews.
- Analyze customer ratings across product categories.
- Compare product-wise average ratings.
- Present findings through charts and summary reports.
- Gain practical experience in data analysis using Python.

## 4. Tools and Technologies

- **Programming Language:** Python
- **Libraries:** Pandas, Matplotlib
- **Dataset Format:** CSV
- **Development Environment:** Python IDE or Visual Studio Code

## 5. Dataset Description

The project uses a synthetic dataset containing 1,000 customer reviews with the following columns:

- `Customer_ID` — Unique customer identifier.
- `Product` — Product category.
- `Rating` — Customer rating from 1 to 5.
- `Review_Text` — Written customer feedback.
- `Review_Date` — Date of the review.
- `Sentiment` — Positive, Negative, or Neutral classification.

Sentiment labels are assigned according to the ratings: 4–5 are Positive, 3 is Neutral, and 1–2 are Negative.

## 6. Project Workflow

1. Generate the customer feedback dataset.
2. Load the CSV file using Pandas.
3. Inspect customer reviews and rating distributions.
4. Analyze sentiment counts and product-wise average ratings.
5. Compare sentiment across product categories.
6. Create visualizations using Matplotlib.
7. Export summary CSV files and a text report.

## 7. Analysis Performed

### Rating Analysis

Examined customer ratings from 1 to 5 to understand the distribution of satisfaction levels.

### Product-Wise Rating Analysis

### Product-Wise Sentiment Analysis
