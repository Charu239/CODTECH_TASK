## 1. Project Overview

The Employee Productivity Study is a data analytics project developed using Python. The purpose of this project is to analyze employee productivity and understand how different workplace factors relate to employee performance.

A synthetic dataset containing 1,000 employee records was created for this project. The analysis examines factors such as attendance, working hours, work experience, overtime, training hours, and task completion to identify productivity patterns across departments.

## 2. Project Scope

The scope of this project includes:

- Generating and importing an employee productivity dataset.
- Inspecting and cleaning the dataset using Pandas.
- Handling missing values, duplicate records, and incorrect data types.
- Calculating productivity-related summary statistics and key performance indicators.
- Comparing productivity across departments.
- Analyzing relationships between productivity and attendance, working hours, experience, overtime, training, and completed tasks.
- Creating charts to visualize employee productivity patterns.
- Generating a report containing important findings and business insights.

## 3. Project Objectives

- Understand employee productivity across different departments.
- Examine task assignment and task completion patterns.
- Study the relationship between attendance and productivity.
- Analyze how working hours, experience, training, and overtime relate to productivity.
- Present findings through statistical summaries and visualizations.

## 4. Tools and Technologies

- **Programming Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib
- **Dataset Format:** CSV
- **Development Environment:** Python IDE or Visual Studio Code

## 5. Dataset Description

The project uses a synthetic dataset containing 1,000 employee records with the following columns:

- `Employee_ID`
- `Department`
- `Experience_Years`
- `Work_Hours_Per_Week`
- `Attendance_Rate`
- `Tasks_Assigned`
- `Tasks_Completed`
- `Performance_Rating`
- `Productivity_Score`
- `Overtime_Hours`
- `Training_Hours`

These fields support the analysis of employee performance, workload, attendance, and productivity across departments.

6. Create charts using Matplotlib.
